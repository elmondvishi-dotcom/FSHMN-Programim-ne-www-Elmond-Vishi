Java I — Pasaporta digjitale dhe GitHub

Çfarë realizova

Struktura e Projektit: Krijova depon dhe folderët e kërkuar nga JavaI deri në JavaXIV duke përdorur skedarët .gitkeep për folderët bosh.

Faqja Kryesore (JavaI/index.html): Ndërtova pasaportën digjitale për personazhin e sajuar (Arta Orbita) me gjuhën sq, charset UTF-8, meta viewport, titullin, elementin <h1>, përshkrimin, listën me 3 aftësi dhe navigimin.

Faqja Dytësore (JavaI/rreth.html): Krijova faqen me historinë e personazhit dhe lidhjen relative për kthim në faqen kryesore.


Stilizimi (JavaI/style.css): Zbatova dizajnin visual me CSS tradicionale dhe Media Queries për t'u përshtatur si në ekranet e vogla ashtu edhe në ato të mëdha.
